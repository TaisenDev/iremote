# iremote interface

The desktop fills the session. A compact toolbar keeps the connection, input mode and keyboard visible. Letterbox space is neutral so it does not look like part of Windows. Direct touch and trackpad share the same display but have explicit controls and instructions.

Connection setup uses a contained form with one field per value shown on the PC. The primary action is full width. Errors appear where the connection state is shown. Indigo marks actions and dark charcoal frames the remote image. Text follows UIKit Dynamic Type and touch targets are at least 44 points.
