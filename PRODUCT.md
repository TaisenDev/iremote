# iremote

<!-- impeccable:product-schema 1 -->

## Platform

ios

## Product purpose

Control a Windows PC from an iPad mini over the home network, including without internet access. The iPad shows the PC desktop. Touch gestures, a trackpad mode and a keyboard send input to that same desktop.

## Constraints

The target tablet runs iOS 8 on ARMv7. The Windows receiver runs in the signed-in desktop session. The user starts and pairs that receiver locally. Device settings, certificates and credentials belong to each installation.
